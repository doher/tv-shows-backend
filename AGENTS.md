# Инструкции для агентов

Перед изменением HTTP API прочитай [контракт](README.md#api).
Разбирай и проверяй HTTP-запросы на границе контроллера. Для общего
преобразования исключений в HTTP-ответы используй фильтры NestJS.

Группируй код по возможностям приложения в модулях NestJS. Выноси
бизнес-сценарии модуля в `tasks/`. Реализуй `task` обычной функцией,
которую можно вызвать без NestJS. Сервис получает зависимости через DI
и передаёт их в сценарий через параметры.

Начинай имя сценария с глагола. Если сценарий помещается в один файл,
назови файл по имени функции. Если нужны вспомогательные файлы, собери
их в одноимённой папке и экспортируй функцию сценария из её `index.ts`.

Держи файлы с логикой небольшими и по возможности отводи каждому одну
самостоятельную задачу.

Перед завершением изменений запусти `pnpm test`.
